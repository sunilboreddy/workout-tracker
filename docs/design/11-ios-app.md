# Design: iOS App (Capacitor)

Implements: `docs/requirements/11-ios-app.md`

## Approach: Capacitor wrapper

Capacitor wraps the existing HTML/CSS/JS in a native WKWebView shell with a JS bridge to native plugins. Maximum code reuse — the web layer is `www/index.html`, a near-copy of `index.html` that diverges only where native API replacements are needed. The root `index.html` stays untouched for GitHub Pages.

No Mac needed: builds run on GitHub Actions macOS runners.

## Project structure (feature/capacitor-ios branch only)

```
capacitor.config.json    — app ID, name, webDir: "www"
package.json             — Capacitor + plugin deps
www/index.html           — Capacitor-adapted web layer
ios/                     — Xcode project (generated by cap add ios, committed)
.github/workflows/ios-build.yml
```

## Native API replacements in www/index.html

| Feature | Old | New |
|---|---|---|
| Haptics | `navigator.vibrate(200)` | `Capacitor.Plugins.Haptics.impact({style:'MEDIUM'})` with `navigator.vibrate` fallback for browser |
| Export | `<a download>` click | `Filesystem.writeFile` to CACHE dir → `Share.share({ url: uri })` opens native share sheet; web `<a download>` fallback |
| Import | `<input type="file">` | `FilePicker.pickFiles({ types: ['application/json'] })` with `<input type="file">` fallback; common `processImport(text)` helper shared by both paths |
| Audio (rest timer beep) | `AudioContext` | No change — works in WKWebView with existing unlock-on-touch pattern |
| `localStorage` | as-is | No change for now — ITP less aggressive for home-screen installed apps; backup feature already mitigates |

All replacements use optional chaining (`window.Capacitor?.Plugins?.X`) so every change gracefully falls back to the web implementation when running in a browser.

## Capacitor plugins

```
@capacitor/core + @capacitor/ios + @capacitor/cli
@capacitor/haptics        — ImpactStyle.Medium on rest timer completion
@capacitor/filesystem     — write backup JSON to CACHE before sharing
@capacitor/share          — native share sheet ("Save to Files")
@capawesome/capacitor-file-picker — native file picker for import
```

## GitHub Actions build (macos-latest)

`.github/workflows/ios-build.yml`:
1. `npm ci` → `npx cap sync ios` (syncs www/ into ios/App/App/public)
2. `pod install` in ios/App/
3. `xcodebuild ... CODE_SIGNING_ALLOWED=NO build` — unsigned simulator build for CI validation
4. (Phase 3, after Apple Developer account) add signing secrets and upload to TestFlight

## Signing (Phase 3)

GitHub Actions secrets required:
- `IOS_CERTIFICATE_BASE64` + `IOS_CERTIFICATE_PASSWORD` — distribution cert (.p12)
- `IOS_PROVISIONING_PROFILE_BASE64` — App Store distribution profile
- `APPLE_ID` + `APPLE_APP_SPECIFIC_PASSWORD` — for TestFlight upload via `xcrun altool`

App ID: `com.sunilboreddy.workouttracker`

**Tracked in:** requested directly by the user.
